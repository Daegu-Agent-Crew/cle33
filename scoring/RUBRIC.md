# CLE33 채점 기준표 (RUBRIC v2)

> 작성: 라이카(감수·채점) · 2026-09-23 v1 · **2026-09-25 v2 — 회장님 지시 FB-20260925-01 3원칙(나레이션·표정·말풍선) 반영: 콘티 1·4, 이미지 3·4, 편집 2 (docs/DIRECTIVES.md)**
> 규칙: 각 단계 5개 항목(항목당 통과 1점) → 5점 만점. **3점 미만(2점 이하)이면 재생성 — 최대 2회.** 2회 후에도 미달이면 막힘 보고 후 기본값 진행(4원칙 2번).
> 채점자: 라이카 고정 — **제작자 자기 채점 금지**(조직 철칙). 채점은 단계 산출물 자동검사 통과 직후, 대기 없이(속도 원칙).

## 1. 스토리 뼈대
1. **원작 정합** — 마션(2015) 핵심 사건 순서·인물 관계 왜곡 없음
2. **3화 분할** — 각 화 자체 클라이맥스 + 다음 화 후크, 16쪽 분량 균형
3. **한국어 대사 방향** — 주요 대사가 번역투 아닌 자연스러운 한국어로 계획됨
4. **표기 준수** — "비상업 팬 각색" + 원작 권리자 표기 포함
5. **재현 가능성** — 씬 목록·인물·장소가 콘티로 바로 변환될 구체성

## 2. 콘티
1. **16쪽 구조** — 쪽당 칸 배치 완결, 이야기 흐름 단절 없음. **사건이 건너뛰어지는 지점마다 `나레이션:` 문장(60자 이내, 쉬운 말)으로 메움 — 앞뒤 그림만 보고 흐름이 이해되어야 함 (v2)**
2. **마디 배치** — 발단·위기·클라이맥스가 쪽 단위로 계획됨
3. **대사·효과음** — 한국어, 칸 안에 들어갈 분량(글자 수)으로 조정됨
4. **이미지 지시** — 구도·배경이 이미지 지시문으로 변환 가능하게 기술. **등장 인물 컷마다 표정 필수 기입(예: "놀란 눈·벌어진 입", "이를 악묾") — 표정 없는 컷은 자동검사 대상 (v2)**
5. **캐릭터 정합** — 등장인물 외형이 캐릭터 시트(시드 고정) 기준과 일치

## 3. 이미지
1. **캐릭터 일관성** — 같은 인물이 화·쪽 간 동일 외형
2. **화풍 일관** — SF 코믹 화풍 유지, 다른 화풍 혼입 없음
3. **가독성** — 구도·인물 크기로 상황·감정 판별 가능. **표정으로 감정 상태를 알 수 있어야 함 — 클로즈업이 아닌 컷도 표정이 보이게 얼굴 크기 확보 (v2)**
4. **오염 없음** — 문자 깨짐·기형·논리 위반 요소 없음. **이미지 내장 말풍선의 한글 오자·깨짐 없음 — 생성 직후 글자 검수, 2회 재생성에도 실패 시 리더 오버레이 폴백+커밋 메시지에 사유 기록 (v2)**
5. **규격 준수** — 칸 규격·해상도·파일명 규칙 준수

## 4. 편집
1. **순서·완결** — 16쪽 순서 정확, 누락·중복 없음
2. **대사 삽입** — 말풍선 위치·읽기 순서 명확, 본문 가림 없음. **말풍선은 이미지 내장이 1순위·리더 오버레이는 폴백; 나레이션은 내레이션 박스(회색 바탕·기울임)로 렌더링하고 '그림만 보기' 토글에서는 숨김 (v2)**
3. **한국어 조판** — 폰트·줄바꿈 자연스러움
4. **저작권 표기** — 표지·마지막 쪽 팬 각색 표기 유지
5. **자동검사** — 깨진 이미지·빈 쪽 등 무결성 결함 없음

## 5. 발행
1. **자동 발행 완료** — 사전 승인 없이 파이프라인 종단 통과
2. **웹 리더 렌더** — GitHub Pages에서 3화 전부 열람·이미지 로딩 정상
3. **현황판 갱신** — 채점 결과 포함 1페이지 자동 갱신 반영
4. **기록 보존** — 발행 로그·채점 기록이 state/에 남음
5. **접근성** — 모바일 폭에서 가로 스크롤 없이 열람 가능
