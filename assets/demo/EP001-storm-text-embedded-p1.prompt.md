첨부된 캐릭터 시트의 외형·화풍·색감을 그대로 유지해 만화 한 페이지 이미지를 생성해줘. 세로형 만화책 한 페이지(비율 2:3). 화풍: SF 코믹북 스타일, 깔끔한 굵은 선, 밝은 채도, 감정이 읽히는 만화적 과장 표정. 배경: 화성 초강력 모래폭풍(적갈색 먼지 사선, 시야 거의 없음). 페이지 상단에 제목 띠: 「폭풍, 그리고 혼자 1/2」. 4칸 구성(세로로: 큰 와이드 → 중간 → 중간 → 하단):
[칸1 와이드] 우주복 5인(시트 외형 그대로)이 폭풍에 휘청이며 걷는 모습. 회색 나레이션 박스(흰 글자): 「솔 18, 화성 초강력 모래폭풍」. 선장 루이스(헬멧 속 절박한 표정, 이를 악묾) 흰 말풍선(검은 글자): 「전원 철수! MAV로 뛰어!」
[칸2] 날아오는 안테나 파편이 왓트니의 옆구리(우주복)를 강타하는 순간. 왓트니 큰 눈·벌어진 입 공포 표정. 붉은 효과음 글자: 「콰앙!」 왓트니 뾰족 말풍선: 「으아악! 배에—!」
[칸3] 루이스 클로즈업, 헬멧 속 눈물 그렁·커진 눈, 절규 표정. 톱니 모양 절규 말풍선: 「왓트니!!」
[칸4] 손목 생체모니터 화면 클로즈업, 수평선 파형과 숫자 0, 주변은 어둡게. 루이스 낮은 대사 말풍선: 「…신호가 끊겼어」. 하단 나레이션 박스: 「생체 신호 없음 — 사망 판정」
규칙: 모든 한국어 글자를 오탈자·깨짐 없이 정확히 렌더링할 것. 말풍선은 흰 배경 검은 글자, 나레이션 박스는 회색 배경 흰 글자, 글자는 명확히 읽히는 크기. 페이지 하단 귀퉁이에 작게 「1」 표기. 클로즈업이 아닌 칸도 인물 표정이 보이도록 얼굴 크기 확보.

실행 지시: 방향은 이미 확정되어 있다(시트 충실형 + 한국어 대사 가독성 우선 결합). 추가 질문·선택지 제시·확인 요청 없이 이 프롬프트 하나로 즉시 이미지를 생성하라. 생성 후 대화 없이 종료.
