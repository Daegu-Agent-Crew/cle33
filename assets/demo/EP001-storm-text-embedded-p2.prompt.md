첨부된 캐릭터·기체·배경 시트의 외형·화풍·색감을 그대로 유지해 만화 한 페이지 이미지를 생성해줘. 세로형 만화책 한 페이지(비율 2:3). 화풍: SF 코믹북 스타일, 깔끔한 굵은 선, 밝은 채도, 감정이 읽히는 만화적 과장 표정. 페이지 상단에 제목 띠: 「폭풍, 그리고 혼자 2/2」. 4칸 구성(세로 배치):
[칸1 와이드] 붉은 모래폭풍 속으로 이륙선 MAV(시트 외형 그대로)가 화염과 분진을 내며 이륙하는 원경. 회색 나레이션 박스(흰 글자): 「아레스 3, 다섯 명이 화성을 떠났다」. 작은 삽입 컷: 헬멧 속 눈물 흘리는 루이스의 얼굴, 말풍선: 「미안해… 왓트니」
[칸2] 붉은 모래밭에 엎어져 의식 없는 왓트니, 옆구리 우주복에 안테나 파편이 박힌 채, 헬멧 유리에 김. 넓고 고요한 구도로 고독감. 나레이션 박스: 「사망 판정 — 단 한 사람이 남겨졌다」
[칸3] 해베 내부(시트 참조), 왓트니가 스스로 옆구리 상처를 봉합하는 장면. 이마에 식은땀, 다문 입·굳은 눈빛의 결심 표정. 말풍선: 「죽을 순 없지」
[칸4 하단 와이드] 왓트니가 손에 든 기록용 비디오카메라를 향해 씩 웃는 클로즈업. 절반쯤 올라간 입꼬리, 장난기 도는 눈. 큰 말풍선: 「좋아, 과학으로 해결한다」. 하단 나레이션 박스: 「솔 18 — 나의 생존 기록, 시작」
규칙: 모든 한국어 글자를 오탈자·깨짐 없이 정확히 렌더링할 것. 말풍선은 흰 배경 검은 글자, 나레이션 박스는 회색 배경 흰 글자, 글자는 명확히 읽히는 크기. 페이지 하단 귀퉁이에 작게 「2」 표기. 클로즈업이 아닌 칸도 인물 표정이 보이도록 얼굴 크기 확보.

실행 지시: 방향은 이미 확정되어 있다(시트 충실형 + 한국어 대사 가독성 우선 결합). 추가 질문·선택지 제시·확인 요청 없이 이 프롬프트 하나로 즉시 이미지를 생성하라. 생성 후 대화 없이 종료.
