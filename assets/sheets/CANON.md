# 외형 표준 기술문 (CANON) — 삽화 프롬프트 필수 동봉

> 목적: 시트 이미지 참조만으로는 외형 재현이 불안정하여, 생성 프롬프트에
> 아래 기술문을 **항상 같이** 넣는다 (회장님 지시 2026-09-24: "생성해둔 자원이
> 이미지 생성 시 제대로 활용되어야"). 근거 시트와 함께 사용.

## 왓트니 (CS-01)
30대 중반의 다부진 체격, 밝은 구리빛 피부, 짧고 헝클어진 갈색 머리, 장난기 섞인 미소.
우주복: 흰색 바탕 + 주황 포인트 하이테크 디자인. 사복: 회색 반팔 티 + 카키 카고 팬츠 + 갈색 전술 부츠.
부상: 왼쪽 복부 붉은 혈흔 파손 흔적.

## 사용 규칙
1. 페이지 삽화 생성 시 해당 컷의 시트 PNG를 `-i` 참조로 붙인다.
2. 프롬프트 본문에 위 기술문(해당 인물분)을 그대로 포함한다.
3. 대사·자막은 이미지에 넣지 않고 웹 리더가 표시한다(글자·말풍선 금지).
   단, 컷 구도는 대사가 얹힐 여백(상단 자막줄, 인물 입 근처 여백)을 고려한다.
4. 생성 후 이미지 분석 도구로 시트 대비 외형 일치 검수(샘플링)를 거친다.
