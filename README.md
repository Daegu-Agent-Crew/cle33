## CLE33 4원칙
1. **사람이 먼저** — 모든 보고 "한 줄 요약 → 한 일 → 링크 → 다음 할 일", 쉬운 말
2. **속도** — 분업 병렬, 자동검사 통과 즉시 진행, 막힘 시 24h 보고 후 기본값 진행
3. **퀄리티** — 단계별 5점 채점 게시, 3점 미만 자동 재생성(최대 2회)
4. **확인 창구** — 현황판 1페이지 자동 갱신, 조율은 게시판 카드(1카드=1보고)
