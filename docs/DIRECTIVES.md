## FB-20260925-01 — 스토리 연결·표정·말풍선 (2026-09-25, 디스코드 #댑관리실-대구루)

**적용 대상: EP002·EP003 전 단계 + EP001 재생성분부터 즉시 적용.** 발행은 자동(기존 결정 유지).

### 1. 스토리 요약이 끊기지 않게 — 중간 나레이션 추가
- 문제: 스토리가 잘 요약되지 않아 **중요한 상황이 스킵**되고, 앞뒤 그림이 연결되지 않음.
- 지시: 16쪽 안에 다 표현하기 어려우면 **쪽과 쪽 사이(또는 쪽 안 여백)에 나레이션 텍스트 박스를 넣어** 건너뛴 상황을 메운다.
- 실행 규칙:
  - **콘티(대구루2)**: 쪽 단위 요약에서 사건이 건너뛰어지면 그 지점에 `나레이션:` 항목으로 메울 문장(60자 이내, 쉬운 말)을 명시한다.
  - **편집·리더(대구루)**: 나레이션은 웹 리더에서 내레이션 박스(회색 바탕·기울임)로 렌더링하고, 그림만 보기 토글에서는 숨긴다.
  - **감수(라이카)**: 채점 시 "앞뒤 그림만 보고도 흐름이 이해되는가"를 확인하고, 끊긴 지점에 나레이션이 있는지 검사한다.

### 2. 사람 표정에 신경
- 지시: 이미지의 **인물 표정**에 신경 써서 생성할 것.
- 실행 규칙:
  - **콘티(대구루2)**: 모든 등장 인물 컷의 이미지 지시에 표정을 반드시 기입한다(예: "놀란 눈·벌어진 입", "이를 악묾"). 표정 없는 컷은 자동검사 대상.
  - **이미지(대구루)**: 공통 스타일 키워드에 `감정이 읽히는 과장된 표정` 유지 + 컷별 표정 지시를 프롬프트에 그대로 반영. 클로즈업이 아닌 컷도 표정이 보이게 얼굴 크기 확보.
  - **감수(라이카)**: 이미지 채점 시 "표정으로 감정 상태를 알 수 있는가"를 가독성 항목의 필수 확인점으로 본다.

### 3. 만화·웹툰식 말풍선을 이미지에 직접 생성, 글자 정확도 유지
- 지시: 대사는 **만화/웹툰 형식의 말풍선으로 이미지 생성 시 함께** 넣고, **글자가 정확히** 나타나도록 주의할 것.
- 실행 규칙:
  - **이미지(대구루)**: 컷 이미지 생성 프롬프트에 대사를 말풍선 지시와 함께 포함한다(예: `흰 말풍선에 "…대사…" 정확한 한국어`). 생성 직후 **글자 검수** — 틀리거나 깨진 한글이 있으면 재생성(최대 2회, RUBRIC 규칙 준용).
  - **폴백**: 2회 재생성에도 글자가 정확하지 않으면, 그 컷만 기존 방식(이미지 위에 리더가 말풍선 얹기)으로 대체하고 커밋 메시지에 사유 기록.
  - **감수(라이카)**: 이미지 채점 4번(오염 없음)에 "말풍선 글자 정확(한글 오자·깨짐 없음)"을 포함해 검사한다.
  - **효과음**도 말풍선과 같은 방식(이미지 내장 우선, 폴백 리더 오버레이).

### 참고
- 기존 EP001 웹 리더의 "이미지 위 대사 얹기" 방식은 이 지시의 **폴백 방식**으로 위치가 바뀜(1순위: 이미지 내장 말풍선).
- 관련 RUBRIC 항목(콘티 1·4, 이미지 3·4, 편집 2) 해석을 위 3원칙에 맞춰 적용한다. RUBRIC 문서 수정은 라이카 담당.
